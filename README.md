# Flow

Flow is a visual, node-based dataflow editor. Build data pipelines by dragging modules onto a
canvas and wiring them together — transform, encrypt, hash, merge, and split data without writing
code, and extend it with your own modules.

This repository hosts distribution downloads only — no source code is published here.

## Download

Grab the latest installer from the [Releases page](https://github.com/siprikorea/flow/releases/latest).

| Platform | File |
|---|---|
| macOS | `Flow-<version>.dmg` |

Windows and Linux builds will be added in a future release.
